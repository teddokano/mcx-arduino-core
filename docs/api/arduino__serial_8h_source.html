108 /*
109 * write(uint8_t)/write(bulk) are declared here (rather than relying on
110 * `using Serial::write;`) because r01lib's own bulk write() returns
111 * status_t (0 = success), which would silently read as "0 bytes
112 * written" if exposed directly to sketches expecting Print's
113 * size_t-bytes-written contract. Declaring write() here also hides
114 * Print's const char* overloads by name (same as it hides r01lib
115 * Serial's own write()), so `using Print::write;` brings those back.
