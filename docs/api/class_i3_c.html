Detailed Description

I3C class

A master-mode I3C driver, derived from I2C. Supports native I3C-SDR transactions (dynamic addressing via DAA, CCC broadcast/direct commands, IBI) as well as running the same physical bus in legacy I2C mode (see mode()) for targets that don't speak I3C.
