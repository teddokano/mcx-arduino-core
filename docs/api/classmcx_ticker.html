Detailed Description

Calls a function every given time, or once after it.

Each object calls its own function: make as many as needed. The functions run in the SysTick interrupt, at the lowest priority: other interrupts, Serial's among them, still run while one does, and millis() reads the time of this tick. Keep them short, and don't wait in them for time to pass. A function may attach() or detach() any mcxTicker, its own included.

Times are rounded to whole milliseconds, at least 1. The first call comes at least the given time after attach(); after that, calls are a period apart. A call that would come while interrupts are off for more than a period is skipped, and the calls keep their timing. Objects due in the same millisecond run in the reverse order of their attach().
