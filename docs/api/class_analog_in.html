◆ AnalogIn()

AnalogIn::AnalogIn ( int pin)
explicit

Construct and configure an analog input on the given pin.

Resolves pin to an LPADC0 channel_id / input_positive pair, performs peripheral init (first instance only) and per-channel LPADC_SetConvCommandConfig. Calls panic() if pin is not a supported analog pin on the current target.

Parameters
pinLogical analog pin (e.g. A0..A3).
