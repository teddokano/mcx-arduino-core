◆ set()

void MsTimer2::set ( unsigned long ms,
void(* f )() )

Stops the timer, and sets func to be called every ms milliseconds once start() runs. A period of 0 is taken as 1.

func runs in the SysTick interrupt, at the lowest priority: other interrupts, Serial's among them, still run while it does, and millis() reads the time of this tick. Keep it short, as on AVR.

msperiod in milliseconds
