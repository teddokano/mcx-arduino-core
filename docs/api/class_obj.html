Detailed Description

Common base class for r01lib peripheral driver classes (I2C, SPI, Serial, DigitalInOut, ...).

Its only job is guaranteeing init_mcu() (chip-level clock/pin bring-up) runs exactly once, the first time any peripheral object is constructed – regardless of which peripheral class gets instantiated first. Every r01lib peripheral class derives from Obj so this happens automatically without each of them needing its own explicit "have I initialized the chip yet?" check.
