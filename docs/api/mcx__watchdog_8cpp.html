volatile uint8_t * mcx_reset_flags ( void )

The cause of the last reset, as AVR's MCUSR: the MCX_RESET_* bits, read from the chip's reset status at the first call. Writable, as MCUSR is (MCUSR = 0;), but only the copy changes. Unlike AVR's, it holds the last reset only: the flags don't add up over resets until cleared.
