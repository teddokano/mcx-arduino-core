Detailed Description

Mbed-compatible AnalogIn implementation for r01lib (FRDM-MCXA153).

Verified against the FRDM-MCXA153 SDK LPADC polling example (examples/driver_examples/lpadc/polling) before writing this file:

  • referenceVoltageSource for VDDA on this board is kLPADC_ReferenceVoltageAlt3 (not Alt1 — Alt1/Alt2/Alt3 are just numbered options; which one is VDDA is board-wiring dependent).
  • powerLevelMode: Alt1 is the lowest power/precision setting and Alt4 the highest (SDK doc order runs low->high), so Alt4 is used here.
  • LPADC_DoAutoCalibration() is required on this part, gated by FSL_FEATURE_LPADC_HAS_CTRL_CAL_REQ (both this feature and ...CTRL_CALOFS happen to be 1 on MCXA153, but CAL_REQ is the one the NXP example actually gates the calibration call with).
  • FSL_FEATURE_LPADC_FIFO_COUNT is 1 on this part, so LPADC_GetConvResult() takes no FIFO-index argument and FIFO reset is LPADC_DoResetFIFO() (no "0" suffix) — the 2-FIFO variants of these calls don't exist here.
