uint8_t SPI::transfer_byte ( uint8_t out)
virtual

Fast scalar single-byte transfer.

Bypasses write()'s generic blocking-transfer per-call overhead (disable/flush-FIFO/clear-status-flags/re-enable), which dominates cost for a single 8-bit frame – this exists for callers that move data one byte at a time in a tight loop (e.g. the standard Arduino SD library's spiRec()/spiSend()).

Parameters
outbyte to transmit
Returns
byte received
