Detailed Description

The watchdog behind <avr/wdt.h> and the bundled WDT library (UNO R4's interface). Internal: sketches use one of those two.

  • FRDM-MCXA153, FRDM-MCXA156, FRDM-MCXN947, FRDM-MCXN236: the WWDT, clocked at 1MHz (a 250kHz count), set to the time asked for. It can't be stopped once started (its WDEN and WDRESET only clear on a reset), so after mcx_wdt_disable() the core's 1ms SysTick interrupt feeds it.
  • FRDM-MCXC444: the COP, whose one-time setting (SIM_COPC) is left at its reset value, 1024ms on the 1kHz LPO: the startup code turns the COP off unless the sketch includes a watchdog header (see mcx_sketch_wdt_event()). The SysTick interrupt feeds it, and resets the board itself (NVIC_SystemReset()) once the time asked for has passed since the last mcx_wdt_reset(), so the reset comes within 1ms of it. The COP only resets the board when interrupts stop (a hang with them off, a HardFault), within 1024ms.

While enabled, panic() and a HardFault (which ends in panic()) end in a watchdog reset, after the message is sent; after mcx_wdt_disable() they stop as they do without a watchdog.

The WWDT and the COP both stop counting while a debugger halts the CPU.

Function Documentation

◆ mcx_reset_flags()

volatile uint8_t * mcx_reset_flags ( void )

The cause of the last reset, as AVR's MCUSR: the MCX_RESET_* bits, read from the chip's reset status at the first call. Writable, as MCUSR is (MCUSR = 0;), but only the copy changes. Unlike AVR's, it holds the last reset only: the flags don't add up over resets until cleared.
