◆ irq_handler()

void irq_handler ( int num)

Common GPIO interrupt dispatcher.

Called by each per-bank GPIOn_IRQHandler/PORTx_DriverIRQHandler defined in irq.c (the actual vector table entries, force-linked via –whole-archive so they override the startup file's weak defaults). Clears the bank's pending interrupt flags, then calls every registered per-pin callback (InterruptIn::rise()/fall()/low()) whose flag is set.

Parameters
numGPIO bank/port index (chip-specific numbering; see irq.c's gpio_ptr[]/ports[] tables)
