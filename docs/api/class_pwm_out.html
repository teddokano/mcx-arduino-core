◆ PwmOut()

PwmOut::PwmOut ( int pin)
explicit

Construct and configure a PWM output on the given pin.

Resolves pin to a FlexPWM0 submodule/channel pair, performs module-level init (first instance only: clock, fault-disable), and sets up the submodule/channel with a default 20ms period, 0% duty. Calls panic() if pin is not a supported PWM pin.

Parameters
pinLogical PWM-capable pin (e.g. D3..D8 mapped to ports 1-6 above).
