6 * Arduino-compatible Print class -- a hardware-independent abstract base
7 * for anything bytes can be written to. This is an original, from-scratch
8 * implementation matching the Arduino Print API surface, not a port of
9 * ArduinoCore-avr/ArduinoCore-API's Print.cpp (which is LGPL 2.1).
10 *
11 * A derived class only needs to implement write(uint8_t) (and optionally
12 * the bulk write(const uint8_t*, size_t) for efficiency) to get every
13 * print()/println() overload below for free -- matching how real Arduino
14 * libraries expect to inherit from Print.
15 */
