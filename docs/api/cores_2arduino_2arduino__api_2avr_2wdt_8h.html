Detailed Description

avr-libc's watchdog interface, on this board's watchdog (see mcx_watchdog.h for how each board does it): 

#include <avr/wdt.h>

void setup() {
  if (MCUSR & _BV(WDRF)) { ... }   // the last reset was the watchdog's
  MCUSR = 0;
  wdt_enable(WDTO_2S);
}
void loop() {
  wdt_reset();
  ...
}

Differences from AVR:

  • The watchdog can't be stopped once started (the hardware can't be, on any of these boards). wdt_disable() stops it resetting the board: the core feeds it from then on.
  • While it is enabled, panic() and a HardFault end in a watchdog reset, once their message is out.
  • MCUSR holds the cause of the last reset only (WDRF, PORF, EXTRF, BORF); on AVR the flags add up over resets until cleared. Writing it only changes this copy.
  • On FRDM-MCXC444, a sketch that includes this header has the COP left on from reset (1024ms), fed by the core: one that keeps interrupts off for a second or more is reset by it, enabled or not.
