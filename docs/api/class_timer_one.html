void TimerOne::attachInterrupt ( void(* isr )())

Calls isr at the end of every period, from the interrupt, at the lowest priority (as millis()'s SysTick): other interrupts, Serial's among them, still run while it does. Keep it short, as on AVR. A period that ended while no function was attached is called for at once, as on AVR.

Parameters
isrfunction to call

void TimerOne::setPeriod ( unsigned long microseconds)

Changes the period, and leaves the timer running (it starts it if it was stopped), as on AVR. The next period is the new one; on FRDM-MCXC444 it is counted from now.
