1/*
2 * @author Tedd OKANO
3 *
4 * Released under the MIT license
5 *
6 * Arduino-compatible IPAddress class -- an IPv4 or IPv6 address that the
7 * network base classes (Client, Server, UDP) and the libraries built on
8 * them pass around. Original implementation matching ArduinoCore-API's
9 * IPAddress interface (so code written for UNO R4 and other ArduinoCore-API
10 * cores builds unchanged), not a port of its IPAddress.cpp (LGPL 2.1).
11 *
12 * An IPv4 address is kept in the last 4 of the 16 bytes, as an IPv4-mapped
13 * address would be, so the integer form (operator uint32_t) and the raw
14 * bytes line up with the other cores.
15 */
