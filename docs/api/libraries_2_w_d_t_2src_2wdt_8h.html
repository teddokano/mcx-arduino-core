WDTimer WDT

Detailed Description

The Arduino UNO R4's WDT library interface, on this board's watchdog (the core's mcx_watchdog.h, the same one as <avr/wdt.h>): 

#include <WDT.h>

void setup() {
  if (!WDT.begin(2000)) { ... }   // 2 seconds
}
void loop() {
  WDT.refresh();
  ...
}

As on the UNO R4, begin() works once (a second call changes nothing), and there is no way to stop the watchdog. While it runs, panic() and a HardFault end in a watchdog reset, once their message is out. Different from the UNO R4's: the range of begin() (1ms to 67108ms here) and what getCounter() returns (milliseconds left, not the hardware's count).
