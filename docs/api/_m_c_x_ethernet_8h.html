MCXEthernet: the on-board Ethernet of FRDM-MCXN947, with the official Ethernet library's interface

The classes and the global object have the official library's names (Ethernet, EthernetClient, EthernetServer, EthernetUDP), so a sketch written for it moves over by changing #include <Ethernet.h> to #include <MCXEthernet.h>. The header has its own name so that the official library, for W5x00 shields, stays usable on every board; the two can't be included in one sketch.

TCP/IP is lwIP on the chip's ENET and the board's LAN8741A PHY. lwIP runs in a 1 ms CTIMER2 interrupt, so connections are served while the sketch is busy or in delay(), as they are by a W5x00. Every call here into lwIP masks that interrupt only. Connections and UDP sockets that can be open at once
