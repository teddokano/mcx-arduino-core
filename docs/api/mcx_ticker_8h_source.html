1/*
2 * @author Tedd OKANO
3 *
4 * Released under the MIT license
5 *
6 * mcxTicker: calls a function every given time, or once after it, from an
7 * interrupt, with any number of objects. The interface is that of the
8 * Ticker in the ESP32 and ESP8266 cores (attach(), attach_ms(), once(),
9 * once_ms(), detach(), active()), written from scratch; a sketch written
10 * for it moves here by changing `#include <Ticker.h>` to
11 * `#include <mcxTicker.h>` and the class name `Ticker` to `mcxTicker`.
12 * The name differs because other Arduino libraries have a class named
13 * Ticker too.
14 *
15 * It runs on the core's 1 ms SysTick interrupt (millis()'s), so it takes
16 * no timer and no pin, and times are in whole milliseconds.
17 */
