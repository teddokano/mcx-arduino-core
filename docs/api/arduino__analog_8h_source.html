28/*
29 * analogWriteFrequency() is not part of the official Arduino API --
30 * it's a de facto extension some vendor cores provide (e.g. Teensy's
31 * analogWriteFrequency(pin, freq)), included here for the same reason:
32 * official Arduino never standardized PWM frequency control since AVR's
33 * timers can't do it cleanly.
34 *
35 * Sets the given pin's PWM period to 1/frequency, preserving its
36 * current pulse width in microseconds (same semantics as PwmOut::
37 * period()/period_us() -- the duty cycle *ratio* is not preserved
38 * across a frequency change, only the absolute pulse width, clamped to
39 * the new period if it no longer fits).
40 *
41 * Caveat: PWM0-5 pair up two-to-a-FlexPWM-submodule (PWM0/PWM1,
42 * PWM2/PWM3, PWM4/PWM5), and a submodule's period register is shared by
43 * both channels -- changing one pin's frequency changes its paired
44 * pin's frequency too. See this board's PIN_MAPPING_*.md.
45 *
46 * @param pin_num PWM pin (PWM0..PWM5)
47 * @param frequency new PWM frequency in Hz; call this before analogWrite() to set duty at the new rate
48 */
49void analogWriteFrequency( int pin_num, uint32_t frequency );
50

55 * only -- calling it does nothing.

57 * @param mode ignored
