Detailed Description

Arduino-compatible I2C (Wire) class.

Wraps an r01lib I2C (or, when sda_pin/scl_pin are this board's I3C pins, an I3C running in legacy I2C_MODE) behind the classic Arduino two-phase Wire API: beginTransmission()/write()/ endTransmission() buffer up a transaction locally, sent as one write() to the target on endTransmission(); requestFrom()/available()/read() work the same way for reads.
